# NetHGL project page

Source of <https://nethgl.github.io>, the project page for **NetHGL: Network-aware
Hierarchical Graph Learning**.

The site is static: `index.html`, `style.css`, `page.js` and the images in `assets/`. It has
no build step and no external dependencies.

To preview it locally:

```sh
python3 -m http.server 4173
```

Then open <http://localhost:4173>.

Code: <https://github.com/tracyhann/NetHGL>
